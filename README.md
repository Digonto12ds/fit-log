# FitLog 🏋️

FitLog is a modern workout library and workout planning application built with Next.js and TypeScript. It allows users to explore different workouts, create a daily workout plan, save workouts, and track completed exercises.

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- React Toastify
- REST API
- Next/Image

## ✨ Key Features

### 1. Workout Library
Browse a collection of workouts with useful information such as:
- Workout name
- Muscle groups
- Equipment
- Duration
- Calories burned
- Rating

### 2. Add Workouts to My Plan
Users can add workouts to their daily plan and manage their selected exercises easily.

### 3. Save Favorite Workouts
Users can save workouts for quick access later and manage their saved workout list.

### 4. Track Completed Workouts
Users can mark planned workouts as completed using the **Mark as Done** button and receive a confirmation toast.

### 5. Workout Statistics & Sorting
The My Plan page provides live workout statistics including:
- Total exercises
- Total minutes
- Total calories

Users can also sort workouts by duration, calories, or rating.

## 📱 Responsive Design

FitLog is fully responsive and designed to work smoothly across:

- 📱 Mobile
- 📲 Tablet
- 💻 Desktop
